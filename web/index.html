how to start.

three simple steps to get your university schedule into telegram.

01

export schedule

open your university outlook calendar online, go to settings, and export your calendar as an .ics file.

02

get the code

generate your unique invite code below. this helps us link your schedule securely to your telegram account.

03

upload to bot

send the code to @uitime_bot, select 'upload schedule', and drop your .ics file directly into the chat.

about the project.

built with modern tech to be fast, stateless, and secure.

uitime is a stateless, microservice-based telegram bot designed to keep your university schedule always at your fingertips. it ensures data privacy by relying on jwt authentication and storing only the absolute minimum required data.

tech stack & skills applied:

c# / asp.net core python / aiogram 3 postgresql entity framework restful api design jwt authentication stateless architecture ci/cd & docker
